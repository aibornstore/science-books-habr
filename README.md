# Science Books - Habr Articles

Серия статей "1001 доказательство" для публикации на Habr.

## Статьи

Каждая статья содержит:
- Введение в тему
- Описание серии книг
- Ссылки на GitHub

## Публикация

Для публикации на Habr:
1. Скопируйте содержимое .md файла
2. Вставьте в редактор статей Habr
3. Добавьте теги: математика, точные науки, доказательства
4. Опубликуйте
